# Teacher page layout

The existing white and blue theme, artwork, exam behavior and permissions are retained. Teacher pages now prioritize actions and show secondary instructions when opened.

- The main sidebar uses stationary icon buttons with one shared, portaled label for pointer hover or keyboard focus. Labels cannot be clipped by the scrolling rail. Escape dismisses the label. Buttons keep their height on short screens.
- The home/assistant view has school counters, three illustrated actions, direct shortcuts and recent exams. Repeated workflow prose and the promotional history card have been removed. Provider switching, conversations, bank attachment and assistant commands remain available.
- Tools are eight compact icon tiles. Selecting a tile opens a native HTML dialog with keyboard containment, Escape, a close control and focus restoration. Descriptions and calculator instructions are disclosures. Grade, subject, semester, search, favorites and external references remain available.
- The bank page begins with a colored folder and book gallery, search, sorting and grid/list controls. Folder creation and book moves are saved per teacher and included in backups. Import/request preparation and original PDF upload are available from the action row. Prompt editing is optional, under “عرض الطلب وتعديله”. Selected books show question filters and cards; file operations, original pages, advanced generation and exam creation are separate disclosures. See [BOOK-LIBRARY.md](BOOK-LIBRARY.md).
- Exams have illustrated subject cards, status counts/tabs, grade filtering and search. Clearing filters from an empty result restores the full list. Creation, editing, publication and copying exam codes use existing handlers.
- Students have class/section folders with counts and combined search. CSV import/export, add student, codes and camera exemptions remain available. Teacher preview login is under “تجربة حساب طالب”. Grouping uses the original grade and section values and does not alter eligibility or student data.

Live monitoring and results now share **المتابعة والنتائج**. Its summary cards, exam progress, filters and student table preserve publishing, review, export and availability actions. The blue orb opens a temporary live classroom; late-answer review remains a separate action. See [LIVE-LAB.md](LIVE-LAB.md) for device/camera behavior and [STUDENT-COMPANION.md](STUDENT-COMPANION.md) for the fixed exam indicator.

Validation: `npm run test:desktop:layout` covers pointer stability at 600/768/1080 screen heights, hover/focus labels, Escape/focus restoration, calculator use, preserved collapsed bank inputs, exam filters and class/section search. It captures teacher layouts at 760, 1024, 1366 and 1920 widths in `test-results/layout-*.png`. `npm run test:desktop:tools` exercises all eight tools, graph handoff and teacher/student permissions. `npm run test:ui` exercises the full bank import, editing, offline recovery and exam workflow. `npm test` covers backend and pure utility behavior.
